## Projets phares
- **embedded-voltage-monitor**: Acquisition analogique, conversion précise et affichage sur écran LCD.  
- **iot-energy-dashboard**: Gateway MQTT, stockage InfluxDB et dashboard Grafana.  
- **simulink-control-suite**: Modèles Simulink pour identification et synthèse de contrôleurs linéaires.  
- **analog-filter-library**: Bibliothèque de filtres actifs et simulations LTspice.  
- **signal-processing-examples**: Scripts Python pour filtrage, débruitage et transformées.
